# Risu Contextual YouTube BGM

RisuAI의 최근 대화 맥락을 보조 모델에 보내 어울리는 곡을 고르고, 로컬 플레이어에서 YouTube 영상을 BGM으로 재생하는 플러그인입니다.

음원을 추출하거나 다운로드하지 않습니다. YouTube Data API와 공식 IFrame Player를 사용합니다.

## 주요 기능

- AI 응답이 끝났을 때 재생 중인 곡이 없으면 자동 선곡
- 최근 대화 3–12개를 반영한 보조 모델 선곡
- 같은 곡·영상·아티스트의 잦은 반복 방지
- 8분 초과 영상과 Shorts 제외
- 개인 사용자의 클린 음원·가사 영상을 우선 탐색
- 임베드 불가 영상이나 재생 실패 영상 자동 건너뛰기
- 원하는 곡을 직접 대기열에 추가
- 다음 곡 미리 준비 및 1–15초 자동 크로스페이드
- 이동 가능한 `Now Playing` 플로팅과 재생 이력 표시
- RisuAI 플러그인 자동 업데이트 지원

## 준비물

- Node.js 20 이상
- YouTube Data API v3가 활성화된 Google API 키
- `otherAx` 보조 모델이 설정된 RisuAI
- RisuAI 데스크톱판 또는 로컬 설치판 권장

## 설치

### 1. 로컬 플레이어 실행

저장소를 내려받아 압축을 푼 다음 `start-local-player.bat`을 더블클릭합니다.

첫 실행에서는 다음 항목을 한 번 입력하거나 선택합니다.

1. YouTube Data API v3 키
2. 전용 자동재생 브라우저 사용 여부 (`Y`/`N`)

`Y`를 선택하면 Edge 또는 Chrome이 별도 전용 프로필과 자동재생 옵션으로 열립니다. 플레이어는 음소거 상태로 재생을 먼저 시작한 직후 소리를 복원해 첫 곡의 클릭 요구를 줄입니다. `N`을 선택하면 기본 브라우저가 열리며 첫 곡에서 `소리 재생 허용`을 눌러야 할 수 있습니다.

도우미가 준비되면 플레이어 창이 자동으로 열립니다. BGM을 사용하는 동안 BAT 터미널 창을 닫지 마세요.

### 2. RisuAI 플러그인 가져오기

BAT 실행 후 생성되는 다음 파일을 RisuAI 플러그인 설정에서 가져옵니다.

```text
risu-plugin/local/contextual-youtube-bgm-v0.4.3.local.plugin.js
```

공개 저장소에 들어 있는 `risu-plugin/contextual-youtube-bgm.plugin.js`와 버전명이 붙은 원본 파일에는 보안을 위해 helper token이 없습니다. **최초 설치에는 반드시 `risu-plugin/local/`에 생성된 파일을 사용하세요.**

개발 중이라면 `Import plugin with hot reload`로 가져올 수 있습니다. 플러그인이 요청하는 `replacer` 권한은 AI 응답 완료 감지에, `mainDom` 권한은 Now Playing 플로팅 표시에 사용됩니다.

### 3. 기본 설정 확인

플러그인 인자는 일반적으로 다음 값으로 둡니다.

| 인자 | 기본값 | 설명 |
|---|---:|---|
| `helper_url` | `http://127.0.0.1:43127` | 로컬 도우미 주소 |
| `helper_token` | 비워 둠 | BAT이 로컬 플러그인에 자동 삽입 |
| `context_messages` | `6` | 보조 모델에 보낼 최근 메시지 수, 3–12 |
| `enabled` | `on` | 자동 선곡 사용 여부 |

## 사용법

채팅 입력부 메뉴의 `Contextual BGM` 버튼을 누르면 제어 창이 열립니다. 여기에서 다음 기능을 사용할 수 있습니다.

- 재생, 일시정지, 정지, 다음 후보
- 최근 대화 컨텍스트 개수 설정
- 자동 선곡 켜기·끄기
- 자동 크로스페이드 켜기·끄기 및 시간 설정
- `아티스트 - 곡명` 형식으로 원하는 곡 대기열에 추가
- 보조 모델 선곡 지침 수정
- 재생 이력 확인 및 초기화
- Now Playing 플로팅 표시 여부 설정

수동으로 넣은 곡은 자동 선곡용 반복 방지 제한을 적용하지 않습니다.

## Now Playing 플로팅

채팅 화면 오른쪽 위에 현재 상태가 한 줄로 표시됩니다.

- 재생 중: `Now playing: 곡명 - 아티스트`
- 일시정지: `Paused: 곡명 - 아티스트`
- 크로스페이드: `Crossfading to: 다음 곡명`
- 곡 없음: `Waiting...`

플로팅 표면에서 왼쪽 버튼으로 드래그하면 위치를 바꿀 수 있습니다. 위치는 기기에 저장되며, 곡명이 길어지면 오른쪽 끝은 고정된 채 왼쪽으로 늘어납니다.

드래그 가능 범위를 바꾸려면 플러그인 원본 상단의 `NOW_PLAYING_DRAG_BOUNDS`를 수정합니다. `left`, `top`, `right`, `bottom` 값은 각 화면 가장자리에서 확보할 여백(px)입니다. 최초 위치는 `NOW_PLAYING_DEFAULT_OFFSET`에서 조정할 수 있습니다.

## 자동 크로스페이드

자동 크로스페이드를 켜면 현재 곡 종료 약 45초 전부터 다음 곡을 준비합니다. 수동 대기열이 있으면 대기열의 첫 곡을 사용하고, 없으면 최근 대화 맥락으로 보조 모델 선곡을 시작합니다.

지정한 마지막 1–15초 동안 두 YouTube 플레이어의 볼륨을 교차시킵니다. 브라우저가 다음 영상의 자동재생을 차단하거나 준비가 늦으면 현재 곡 종료 후 일반 재생으로 전환됩니다.

자동 선곡을 꺼도 수동 대기열 곡 사이의 크로스페이드는 동작합니다.

## 선곡 및 재생 규칙

1. AI 응답이 저장되고 현재 곡이나 진행 중인 선곡 작업이 없을 때 자동 선곡을 시작합니다.
2. 최근 메시지와 반복 차단 목록을 `otherAx` 보조 모델에 전달합니다.
3. 로컬 도우미가 후보를 YouTube에서 검색하고 실제 영상 정보를 검사합니다.
4. 8분 초과 영상, 길이를 확인할 수 없는 영상, 명시적인 Shorts 영상은 제외합니다.
5. 개인 사용자의 가사·클린 음원 업로드를 우선하고 Official, Topic, VEVO, 라이브·공연 영상은 후순위로 둡니다.
6. cover, reaction, remix, slowed/reverb 등 다른 소리나 가공이 섞일 가능성이 큰 영상은 후순위로 둡니다.
7. 임베드 오류나 재생 시작 실패가 발생하면 다른 업로드를 자동으로 시도합니다.
8. 실제로 소리가 재생되고 재생 위치가 일정 시간 이상 전진한 곡만 이력에 기록합니다.

YouTube Data API에는 Shorts 여부를 직접 알려주는 전용 필드가 없으므로, 제목·설명·태그에 표식이 전혀 없는 일부 Shorts는 완전히 식별하지 못할 수 있습니다.

## 반복 방지 기본값

- 동일 YouTube 영상: 최근 40곡 및 30일 이내 차단
- 동일 곡의 다른 업로드: 최근 30곡 및 30일 이내 차단
- 동일 아티스트: 최근 8곡 및 7일 이내 차단
- 최대 이력: 500곡

모든 후보가 아티스트 제한에만 걸리면 가장 오래된 아티스트부터 제한을 완화하지만, 동일 곡 제한은 유지합니다.

## 자동 업데이트

플러그인은 RisuAI의 `@version`과 `@update-url` 기능으로 새 버전을 확인합니다. 최초 설치를 토큰 포함 로컬 파일로 완료하면, 이후 토큰 없는 공개 배포 파일로 업데이트되더라도 도우미 연결값을 기기 로컬 저장소에서 이어받습니다.

자동 업데이트는 RisuAI 플러그인 JS만 교체합니다. 릴리스에서 `helper/`가 변경된 경우에는 저장소의 새 ZIP도 받아 로컬 도우미를 교체해야 합니다.

변경 내역은 [CHANGELOG.md](CHANGELOG.md)에서 확인할 수 있습니다.

## 로컬 설정

설정은 `helper/config.local.json`에 저장되며 Git에 포함되지 않습니다.

| 항목 | 설명 |
|---|---|
| `defaultVolume` | 시작 볼륨 0–100 |
| `browserAutoplayBypass` | 전용 자동재생 브라우저 사용 여부 |
| `browserWindowWidth`, `browserWindowHeight` | 전용 플레이어 창의 초기 크기 |
| `recordAfterSeconds` | 재생 이력을 확정할 연속 재생 시간 |
| `playbackStartTimeoutSeconds` | 재생 시작 실패로 판단할 시간 |
| `regionCode`, `relevanceLanguage` | YouTube 검색 지역과 언어 |
| `policy.*CooldownPlays` | 최근 몇 곡 동안 반복을 차단할지 설정 |
| `policy.*CooldownDays` | 며칠 동안 반복을 차단할지 설정 |
| `policy.maxHistory` | 저장할 최대 이력 수 |

전용 브라우저 선택을 바꾸려면 `browserAutoplayBypass`를 `true` 또는 `false`로 수정합니다. 값을 삭제하고 BAT을 다시 실행하면 `Y/N`을 다시 묻습니다.

## 보안과 개인정보

- 서버는 `127.0.0.1:43127`에만 열리고 임의 생성 토큰으로 요청을 인증합니다.
- YouTube API 키는 `helper/config.local.json`에 저장되며 Git에서 제외됩니다.
- helper token은 로컬 설정, BAT이 생성한 `risu-plugin/local/` 설치본, RisuAI의 기기 로컬 플러그인 저장소에만 보관됩니다.
- 로컬 설정 파일과 로컬 플러그인 파일을 다른 사람에게 공유하지 마세요.
- 전체 대화 내용은 로컬 도우미로 보내지지 않습니다. 도우미는 보조 모델이 정한 아티스트·곡명·검색어만 받습니다.

## 문제 해결

### 도우미 연결 실패

1. `start-local-player.bat`이 실행 중인지 확인합니다.
2. RisuAI에 공개 원본이 아니라 `risu-plugin/local/*.local.plugin.js`를 가져왔는지 확인합니다.
3. 플레이어 화면 상단 상태가 연결됨으로 표시되는지 확인합니다.

### 첫 곡에서 소리가 나지 않음

BAT 첫 실행에서 전용 자동재생 브라우저를 `Y`로 선택하는 것을 권장합니다. 기본 브라우저를 사용하면 플레이어의 `소리 재생 허용` 버튼을 한 번 눌러야 할 수 있습니다.

### 영상이 재생되지 않음

일부 영상은 검색 단계에서 임베드 가능으로 표시되어도 권리자 정책이나 Content ID 때문에 실제 플레이어에서 거부될 수 있습니다. 플러그인은 다른 업로드를 자동으로 시도하며, 바로 넘기려면 `다음 후보`를 누릅니다.

### 보조 모델 응답을 해석하지 못함

RisuAI 개발자 도구 콘솔에서 `[Contextual YouTube BGM]`으로 필터링합니다. `auxiliary response envelope`가 `fail`이면 `otherAx` 설정이나 API 상태를 확인하세요. 디버그 로그에는 최근 대화 맥락이 포함될 수 있으므로 외부에 그대로 공유하지 마세요.

## 알려진 제약

- 전용 자동재생 브라우저에서도 운영체제·브라우저·YouTube 정책에 따라 드물게 사용자 클릭이 필요할 수 있습니다.
- 크로스페이드는 두 YouTube 플레이어의 준비 상태와 네트워크 상황에 영향을 받습니다.
- 공식·Topic·VEVO 영상은 외부 임베드를 거부하는 경우가 비교적 많습니다.
- RisuAI를 HTTPS 웹사이트에서 실행하면 브라우저의 로컬 네트워크 정책이 HTTP 도우미 연결을 차단할 수 있습니다.
- 존재하지 않는 곡을 보조 모델이 제안하거나 모든 검색 후보가 실패하면 다음 AI 응답에서 다시 선곡합니다.
- YouTube 검색에는 Data API 할당량이 사용됩니다.
